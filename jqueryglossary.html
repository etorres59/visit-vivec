Jquery Glossary

Form / Control Methods
Method Description Example
val() Gets or sets the value of form elements. $('#name').val(); or $('#name').val('John');
text() Gets or sets the text content of elements. $('#msg').text('Welcome');
next() Selects the next sibling element. $('#input1').next().focus();
submit() Triggers or listens to form submission. $('#form').submit(function(e) { e.preventDefault(); });
focus() Sets focus or binds a focus event to an element. $('#email').focus();
Traversal / Manipulation Methods
Method Description Example
prev() Selects the previous sibling element. $('#input2').prev().hide();
find() Finds descendant elements matching a selector. $('#form').find('input');
attr() Gets or sets attributes of elements. $('img').attr('src', 'new.jpg');
css() Gets or sets CSS properties. $('#box').css('background-color', 'blue');
addClass() Adds a class to selected elements. $('.nav').addClass('active');
removeClass() Removes a class from elements. $('.item').removeClass('hidden');
toggleClass() Toggles class on or off. $('#menu').toggleClass('open');
html() Gets or sets HTML content of elements. $('#msg').html('<b>Success!</b>');
hide() Hides selected elements. $('.modal').hide();
show() Shows hidden elements. $('#dropdown').show();
each() Iterates through each matched element. $('li').each(function(i) {
  console.log($(this).text());
});
Event Methods
Method Description Example
ready() Executes code after DOM is loaded. $(document).ready(function() {
  console.log('DOM Ready');
});
click() Binds a function to click event. $('#btn').click(function() { alert('Clicked!'); });
mouseover() Triggers when mouse enters element. $('#box').mouseover(function() { ... });
hover() Handles mouseenter and mouseleave. $('#item').hover(
  function() { $(this).addClass('hover'); },
  function() { $(this).removeClass('hover'); }
);
Animation Methods
Method Description Example
animate() Performs custom animation using CSS properties. $('#box').animate({ left: '200px' }, 1000);
delay() Delays the next item in the queue. $('#box').delay(500).fadeIn();
stop() Stops the currently running animation. $('#box').stop();
finish() Stops animation and jumps to end state. $('#box').finish();
